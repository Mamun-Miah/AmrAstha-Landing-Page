# AI Image Prompts for AmrAstha Marketing Website

These prompts are designed to generate clean, modern illustrations that represent trust, verification, and Bangladesh commerce themes.

## 1. Hero Section Image
**Prompt:**
```
Clean vector illustration of a Bangladeshi marketplace scene with abstract geometric shapes representing trust and verification. A stylized handshake between two figures with digital verification badges floating around them. Warm color palette with deep blues and greens. Modern, minimalist design with subtle Bangladeshi cultural elements like patterns or architecture. No text, no logos, focus on trust and connection. Mobile-first composition, vertical orientation.
```

**Usage:** Homepage hero section background
**File:** `/public/images/hero-trust.png`

## Design Guidelines for All Images

- **Style:** Clean vector illustration or modern 3D with soft lighting
- **Colors:** Primary colors should be blues and greens (trust, safety)
- **Cultural Elements:** Subtle Bangladeshi patterns or architectural elements
- **People:** Bangladeshi silhouettes or figures without identifiable faces
- **Text:** No text or logos in images
- **Mobile-First:** Consider vertical and horizontal orientations
- **Accessibility:** Ensure good contrast ratios for text overlay

## Technical Specifications

- **Format:** PNG with transparency where needed
- **Resolution:** 1920x1080 minimum for hero images, scalable for vectors
- **File Size:** Optimized for web (<500KB each)
- **Color Profile:** sRGB for web consistency

## Usage Notes

1. Place generated images in `/public/images/` directory
2. Reference them in components using `/images/filename.png`
3. Use Next.js Image component for optimization
4. Add alt text for accessibility
5. Consider dark mode variants where appropriate
